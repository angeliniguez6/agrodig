# Proyecto AGRODIG

Recorrido interactivo y juego en acuarela sobre la propuesta de exportación de fórmula iniciadora para lechones con sucralosa a Guatemala.

Autor: Ángel de Jesús García Iñiguez.

Sitio público: https://angeliniguez6.github.io/agrodig/

Sitio estático: HTML, CSS y JavaScript, sin compilación ni servidor propio. GitHub Pages publica la rama `gh-pages`, carpeta raíz `/`. La rama `main` conserva los archivos fuente. Para actualizar el sitio, aplicar los cambios también en `gh-pages`.

Incluye las ilustraciones, los logos originales y los cuatro sonidos proporcionados por el autor.
