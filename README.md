# Proyecto AGRODIG

Recorrido interactivo y juego en acuarela sobre la propuesta de exportación de fórmula iniciadora para lechones con sucralosa a Guatemala.

Autor: Ángel de Jesús García Iñiguez.

Sitio estático: HTML, CSS y JavaScript. Publicación mediante GitHub Pages, rama `main`, carpeta raíz `/`.

Incluye las ilustraciones, los logos originales y los cuatro sonidos proporcionados por el autor.
